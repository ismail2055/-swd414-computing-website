# Department of Computing Website — SWD414 Assignment

A responsive, static multi-page website created for the assignment **Managing a Web Development Project Using Git and GitHub**.

## Pages
- `index.html` — Home
- `about.html` — About Us
- `programmes.html` — Available programmes (illustrative examples)
- `contact.html` — Contact Us (front-end demo form only)
- `css/style.css` — Styling and responsive layout
- `js/script.js` — Mobile navigation, footer year, and demo form response

## Run the website
Open `index.html` in a web browser. No server or package installation is required.

## Git and GitHub workflow
Use the commands in `GIT_GUIDE.md`. Replace `YOUR-USERNAME` and `YOUR-REPOSITORY` with your own GitHub details. Run the commands yourself so the repository and commit history belong to your account.

## Important customisation
Before submitting, replace the sample contact details and programme list with accurate details if your lecturer expects information from your institution. The contact form is a front-end demonstration and does not send email.
